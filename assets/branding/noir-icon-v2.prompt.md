# NOIR icon v2

Mode: built-in image generation followed by a cleanup edit.

Asset: noir-icon-v2.png. Original v1 preserved. No app code or launcher resources changed.

## Initial prompt

Use case: logo-brand. Asset: a new, striking Android app icon for NOIR, an APK modification developer tool. One square icon, no mockup or presentation. Art direction: dark technical luxury, precise, futuristic, distinctive.
Design an original compact emblem from two interlocking angular white ribbons. Together they create a sharply chamfered, almost hexagonal silhouette suggesting code brackets and a package being opened and rebuilt. Their central black negative space subtly forms a diagonal N. It should feel like an engineered sigil, not an ordinary typed letter N. Strong wide strokes, decisive angular cuts, dynamic offset geometry, intelligent negative space. Two or three large connected geometric components only, no fussy micro-detail. Visually balanced and instantly recognizable at small launcher size.
Composition: center the emblem, occupying about 57% of a square canvas, generous equal padding. Opaque pure black background extending to all four edges. Flat solid white emblem, crisp perfectly smooth vector-like contours. Black-and-white only; neutral grayscale antialiasing is fine. No words, lettering beneath, thin frame, colored light, gradients, textures, distressed edges, shadows, glow, chrome, 3D scene, phone, watermark, or existing brand emblem. Do not create a conventional slab-letter monogram. This is a fresh alternative with a more compelling silhouette and code-inspired personality.

## Final cleanup prompt

Polish this exact NOIR icon into clean finished artwork. Preserve the interlocking angular ribbon emblem and its black negative spaces, position, shape, and black square canvas. Change only the rendering: perfectly smooth solid white faces, perfectly straight crisp contours, perfectly solid black negative space and background. Remove every gray outline, bevel, scratch, ragged edge, speckle, stray triangle, texture, and distressed artifact. Flat opaque white on opaque black, with normal smooth antialiasing only at boundaries. The symbol should appear precision-cut and bold. No gradient, shadow, glow, extra mark, wording, or new decoration. Single square app icon.
